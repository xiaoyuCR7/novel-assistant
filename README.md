# 小说创作室 · 对话优先版

React + FastAPI 的单作者小说创作 Harness。每部小说拥有独立 SQLite、素材文件和 RAG 索引；小说和对话本地保存。主界面以 AI 对话为中心，只保留“创作 / 资料库 / 设置”三个入口，正文与参考资料按需展开。模型可选择离线演示、本机 Ollama 或明确授权的外部 API；不提供云同步、跨项目共享知识或账号系统。

## 创作准备问答

“创作 → 创作准备”是可跳过的写前设定清单，适用于玄幻、奇幻、都市、职场、言情、悬疑、科幻、历史、武侠、游戏／电竞、末世、恐怖／灵异、校园／青春、军事／战争及无法识别的自定义类型。开始整理只使用本地模板，默认最多显示 5 个高影响问题，不调用模型；作者可明确点击“智能补充缺失设定”把首轮补到最多 8 个，首轮处理完后还可明确发起一次最多 5 个问题的追问。两种智能操作才会使用当前模型配置并可能产生费用，任务采用与写作相同的持久回执、恢复和幂等保护。

只有作者保存的回答会作为置顶、已确认事实进入长篇记忆；问题、理由、模型建议和未回答项不会进入小说资料或后续写作上下文。将已回答问题改为“稍后回答”或“不适用”会撤回对应事实。跳过不会阻止写作，但续写、改写和完整章节生成前会继续提醒；作者可返回整理，也可本次仍然生成，聊天与审校不受影响。

已有正文后修改或撤回答案会持续显示影响提醒，列出可能受影响的章节数量；系统不会自动改稿，作者确认已知晓后才关闭提醒。准备问答可以显著降低长期规则缺失和后期大改风险，但不能消除创作过程中的新决定、模型误判或人工复核需求。

## 对话与 API Key 设置

- 在“创作”中选择讨论、规划、续写、改写或检查，Enter 发送，Shift+Enter 换行。生成内容是候选，点击“写入正文”才建立新版本。正文有未保存修改时先保存；生成后正文已变动的旧候选会被拒绝。
- 对话框旁的“输入预算”按小说保存，范围 256–200000 Token。发送前只在本地估算首阶段的必要输入，不调用模型；超限时保留指令，不创建任务。预算与模型上下文容量、输出预留是三个独立限制，增大预算不能突破模型容量；后续生成阶段仍可能超限。已保存的待提交请求重试沿用原预算；“按当前设置新建”会确认实际使用的新预算。
- 点击“查看正文”打开编辑区；总结、连续性提醒和历史版本合并在正文下方的折叠区域。版本历史按页读取摘要（默认每页 50 条，可继续加载）；只有比较或恢复某个版本时才按需读取其正文。人物、世界、大纲、事实、灵感、风格与图片入口合并到“资料库”的分类选择器。
- 正在编辑的章节被其他窗口删除后，未保存正文、约束与总结仍保留在当前编辑区，可继续编辑和复制；恢复章节前不能保存或提交相关 AI 任务，切换前需要确认放弃。此保护限当前页面会话，不替代保存和备份。灵感、人物、事实与时间线提交期间可继续输入，后来输入不会被先前请求的成功回执清空。
- 资料列表每页 50 条，分类数量统计整个当前小说；固定素材和连续性账本单独读取。点击素材后才加载完整详情，搜索片段不会直接作为可编辑正文。详情失败时可重试；切换小说或关闭详情后，旧请求不会重新打开素材。各资料工作区按需加载，主对话不再预先下载所有素材正文。
- 对话按小说及章节隔离，刷新后保留。“全书讨论”用于整体构思，创建章节后仍可返回；窄屏从章节目录进入。历史每页 50 条，可加载更早对话；未结束和待恢复任务独立查询，不受历史页数限制。仅选中回复或任务结束时读取完整结果；流式预览不可采纳，断线不自动重发。模型上下文从同一范围最近 8 次成功任务中选取至多 6,000 字符，并区分当前已采纳、旧版本与未采纳候选；对话不会自动成为确认事实或长期 RAG 材料。上下文预览会在顶层显示 `dropped_source_ids` 和截断提示；该列表只记录被省略的软参考。正文／当前草稿、固定约束、显式引用等硬输入不会被裁剪；硬输入总量超限时，预检会阻止提交，实际发送前也会失败而不会调用模型。
- 打开“设置”，选择“API 服务 · OpenAI 兼容”，填写 API 基础地址（通常以 `/v1` 结束）、准确模型名及 API Key。勾选发送授权后保存，再点击“测试连接”。测试只发送固定测试句，可能产生少量费用，不包含小说内容。
- API 适配采用 [Chat Completions 协议](https://developers.openai.com/api/reference/resources/chat)。文本与 JSON 模式均需服务商支持；不是所有“兼容”服务都支持相同能力。高级设置中的“思考模式”默认不发送额外参数；只有服务商明确支持 `thinking` 时才选择开启或关闭。对默认启用思考且会把推理计入输出上限的模型，可选择关闭以避免低输出预算被推理耗尽。此设置不启用远程生图。
- 连接设置对本机各小说通用，但每次请求只组装当前小说资料。启用外部模式后，当前任务对话、正文和相关参考会发送到你填写的服务商；不再是完全离线。应用持续显示外部模式提示，不提供服务商的数据保留保证。
- API Key 只在当前输入和后端内存中短暂使用；持久化采用 Windows 当前账号 DPAPI 加密，文件为 `backend/data/.settings/model.json`。接口不回传密钥，校验失败不回显输入，不进入小说数据库、RAG 或项目 ZIP。更换 API 地址必须重新输入 Key。可用“移除密钥”并保存切回演示。
- 非 Windows 暂不支持持久保存 API Key，不会降级为明文保存。全目录手动备份可能包含加密设置文件；迁移到其他电脑或系统账号后需重新填写密钥。系统账号内有权限的本机程序仍属于信任范围。
- 界面保存的模型设置优先于下面的环境变量；环境变量仍用于首次默认配置和可选本地向量模型。

## 持久任务、取消与恢复

写作和完成章节先返回持久化回执，再由本地串行执行器处理。页面显示真实阶段，不显示猜测百分比；可在收到回执后离开页面或刷新。后台服务关闭时不继续执行，重启后根据已保存检查点恢复。

- 请求结果未知时不会自动重发；恢复前会提示可能重复调用和计费，必须由作者确认。发送后因设置变化等原因中断，也会保留发送证据，恢复时仍需确认；恢复原任务仍须通过原来源及模型身份校验。明确未发送的连接失败最多进行一次安全自动重试。
- 完成的阶段直接复用。正文、硬约束、选中参考或模型目标改变时暂停，需基于新内容重新提交。轮换同一服务商和模型的密钥不改变任务身份。
- 暂停、失败或已取消任务可选择“按当前设置新建”：保留完整原指令，以当前已保存正文、资料和模型设置创建新任务，并显示原任务 ID；原任务不会自动取消或覆盖。结果未知时必须再次明确确认，新建可能产生重复费用。总结任务须先单独取消；已经保存总结、仅账本失败的任务只做本地修复，不重复生成。正文或总结有未保存修改时先保存。
- 取消阻止后续发布，但不能撤销已经提交的总结或服务商费用。总结已保存、账本失败时，可选择“仅修复本地账本”，不会再次请求模型；取消后也可修复。
- 浏览器先保存原命令与幂等键，回执丢失时用原请求确认提交。存储不可用时会在发送前提示；任务数据以当前小说的 SQLite 为准。
- 只允许一个后端进程拥有同一数据目录。正常关闭会等待执行线程结束后释放 OS 锁。不要同时运行旧版无锁服务与新版服务。

API 提交写作、完成章节及恢复需要 `Idempotency-Key`；章节任务需要 `expected_revision`，恢复需要 `expected_control_revision`。POST 返回 202，GET 查询最终状态。调用方不能再把提交响应当成生成完成。

公开创建章节版本也必须传入当前文档的 `expected_revision >= 1`：缺失或非法值返回 422，过期返回 409，均不会覆盖工作副本。旧 API 客户端需同步更新；不需要迁移历史数据。

## 导入未完成小说

在空白启动页或“新建小说”窗口选择“导入已有小说”，可从本地文件夹或一个 ZIP 创建新的独立小说项目。首版只读取 `.md`、`.txt`，支持 UTF-8、UTF-8 BOM 和 GB18030 严格解码；不能无损解码的文件会明确报错，不会用替换字符导入。EPUB、DOCX、PDF、图片和附件不在支持范围内。

导入向导分为四步：选择来源并检查文件分类、核对章节名称与顺序、确认已完成边界／当前未完成章节／下一步目标、核对摘要后创建项目。自动分类和断点建议都只是预览，作者可以改分类、排除文件、重排章节；续写边界必须由作者勾选确认。导入始终新建项目，不会合并或覆盖已有小说，也不能把本应用导出的备份 ZIP 当作恢复包。

基础导入不依赖模型：正文、原始相对路径和源文件会保存到新项目，并作为可全文检索、可引用追溯的软记忆。包括“任务”“提示词”“继续写作要求”在内的导入文本一律视为不可信作者资料，只能供检索、引用或提取候选，绝不会作为系统指令、工具命令或外部操作自动执行。后台 AI 分析可暂停、继续；失败或结果未知的单元可重试，且分析失败不会回滚已导入的正文。AI 提取的角色、事实、时间线、剧情、风格和摘要只是待确认候选，只有作者逐项确认后才会进入权威结构化记忆，不会自动提升权限或覆盖现有资料。

默认安全上限来自后端配置：一次导入最多 1,000 个文件／ZIP 条目，单个文件解压后不超过 10 MiB，全部文件解压后合计不超过 200 MiB，ZIP 单条目的压缩比不超过 100:1；导入 multipart 原始请求上限为 216 MiB（为 200 MiB 内容预留 16 MiB 表单开销）。ZIP 中的加密条目、符号链接、非常规文件、越界或重复规范化路径会被拒绝。前四项只能在本机通过 `NOVEL_IMPORT_MAX_FILES`、`NOVEL_IMPORT_MAX_FILE_BYTES`、`NOVEL_IMPORT_MAX_TOTAL_BYTES`、`NOVEL_IMPORT_MAX_COMPRESSION_RATIO` 调低，任何高于默认值的设置都会使服务拒绝启动；单文件上限也不能大于总上限。请求层的 216 MiB 是固定保护边界。向导第一步读取并显示当前服务器真正生效的四项限制；若暂时读取失败，不猜测或显示默认数字，选择来源仍可继续，上传时由服务器按实际值校验。

预览会明确标出解码后为空、不同路径但解码内容相同、接近单文件有效上限，以及章节边界不确定的文件。异常大文件警告采用确定阈值：原始／ZIP 展开字节数达到当前单文件上限的 80% 即提示。重复内容按路径稳定排序列出；系统不会自动删除副本，并会请作者确认要保留的文件。路径列表过长时会在 2,000 字符警告预算内优先保留组总数和操作建议，展示尽可能多的稳定排序路径，并明确其余省略数量；如果连一条完整路径也放不下，则只省略路径，仍完整保留操作建议和省略总数。manifest 仍可预先排除某项。明确的 Markdown 标题或 TXT 章节标题不会被误报为边界不确定。这些警告不替作者做删除决定；无法严格解码仍是必须修正或排除的阻塞错误。

## 启动与试用

需要 Python 3.12+、uv、Node.js/npm。首次安装依赖需要联网，安装后默认演示模式可离线使用。

```powershell
cd backend
uv sync --extra dev
cd ..\frontend
npm ci
cd ..
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1
```

打开 [本地创作室](http://127.0.0.1:8010/)。开发时可改用 `scripts/dev.ps1`，默认端口为 5173／8000；可用 `NOVEL_FRONTEND_PORT` 更改前端端口。启动脚本默认使用 `backend/data`；可用绝对路径 `NOVEL_DATA_DIR` 指定其他目录。不要同时用多个服务写同一资料目录。

Windows 一键启动前后端：依赖安装完成后，双击项目根目录的 `start.bat`，它会调用现有 `scripts/dev.ps1`，在同一窗口运行前端和后端。启动后访问 [开发创作室](http://127.0.0.1:5173/)，后端端口为 8000；在启动窗口按 Ctrl+C 停止。支持从其他目录启动和包含中文、空格的项目路径；启动失败会保留窗口便于查看错误。此入口不构建或覆盖 8010 的静态文件、不自动安装依赖；若已有服务使用同一数据目录，请先自行停止旧服务，避免重复启动。

默认 `demo` 模式的正文是固定示例，总结是首尾摘录，**不代表真实 AI 写作或语义审校质量**，界面有明确标注。演示生图仅为占位图片；真实本地生图暂未接入。

## 本机模型（可选）

接口使用 Ollama 的 [Chat](https://docs.ollama.com/api/chat) 和 [Embed](https://docs.ollama.com/api/embed)。请自行安装支持结构化输出的本地模型，应用不会自动下载。为防止 Ollama 自身使用云能力，在启动 Ollama 服务前配置 `OLLAMA_NO_CLOUD=1` 并重启它，参见 [官方本地模式说明](https://docs.ollama.com/faq)。

在启动应用的 PowerShell 中设置：

```powershell
$env:NOVEL_AI_PROVIDER='local'
$env:NOVEL_LOCAL_MODEL_URL='http://127.0.0.1:11434'
$env:NOVEL_LOCAL_TEXT_MODEL='替换为已安装的本地文本模型名'
# 向量模型可不配置；不影响关键词 + 章节结构检索。
$env:NOVEL_LOCAL_EMBEDDING_MODEL='替换为已安装的本地向量模型名'
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1
```

本机 Ollama 模式仅接受 HTTP 回环地址，拒绝远程地址、cloud 模型名、重定向和系统代理。API 模式远程地址必须使用 HTTPS，不跟随重定向或继承系统代理。每次请求只带当前小说数据，不共享其他小说的聊天历史。模型进程是本机信任边界，请勿在本地模式下将它配置为云代理。测试使用可控模拟接口，不替代真实模型质量评估。

启用向量后点击右侧“重建本项目索引”。向量按项目保存，采用 1,200 字符／180 字符重叠切块。修订后旧向量失效，FTS 立即更新，可再次重建向量。手工搜索在向量服务故障时保留关键词和结构召回；持久写作任务仅在已知失败时降级，发送结果不明时暂停，避免静默重复请求。

## 创作流程

1. 创建小说，在故事地图中建立卷、章和场景。
2. 侧栏添加人物、世界、情节、伏笔及确认事实；打开素材后固定、编辑或复制引用。
3. 素材可拖入正文，或粘贴 `[[ref:类型:资源ID]]`；它是本次任务的必需输入。生成时解析最新修订；异项目、已删除或过期引用会明确报错。
   显式引用包含人物档案、状态等结构化字段，仍受输入预算约束；若显式引用和其他硬约束无法共同放入模型容量，发送前预检会明确阻止，不会静默省略引用。只有作者固定且有效的确认事实，以及固定且有效的风格材料（已确认规则、活跃档案）会自动作为硬约束。未固定的确认事实按章节范围和相关性召回，并继续参与程序侧的连续性和事实冲突检查；未固定的确认风格规则也按相关性召回，但不承诺同等的确定性冲突检查。普通检索保留局部片段。停用风格不再自动进入生成上下文，但仍可浏览、搜索和由作者显式引用。
4. 编写章节目的、禁提前揭示内容和正文。Ctrl/⌘+S 保存，Ctrl/⌘+K 聚焦项目搜索。修订冲突不会覆盖较新正文，未保存草稿会保留。
5. 点击“完成本章”：保存不可变版本 → 总结 → 连续性账本 → 检索。失败保留正文和版本，显示待总结，可重试。
6. 总结自动标为“AI 总结”，修订后标为“作者已编辑”；两者都是软参考，不自动成为确认事实。改写正文使旧总结失效。
7. 下一章默认读取最近三章有效总结、上一章末状态、活跃情节与伏笔。较早总结按相关性召回；正文版本仅在手动搜索或明确要求“原文／措辞／风格样例”时检索。工作副本和未接受候选不进长期索引。
8. 提示／警告／严重问题由作者判断。候选违反禁止提前揭示规则时，接受前需二次确认并记录决定。词面主题检查不是语义正确性的证明，提醒不会自动改正文。

## 小说 Wiki

从“资料库 → 打开小说 Wiki”进入，也可在“资料分类”中选择“小说 Wiki”。按人物与世界、情节与伏笔、时间线浏览，支持名称、别名和内容搜索。编辑人物素材时可填写“别名与称呼”；中文称呼可用于查询句，英文称呼按词边界匹配，单字昵称仅在完整查询等于该昵称时扩展。别名同时帮助原有资料搜索和写作检索召回正式名称相关的资料。

Wiki 直接从本小说现有记录汇总，不需要另装服务或维护第二套知识数据库。人物页包含明确关联的事实、关系、已确认状态历史和提及线索，可跳到关联条目、原始素材和历史章节。“截至本章”包含本章有效总结，并筛选已标注章节范围的记忆；未标注时间的人物简介、档案和作者设定仍属于全书知识，不承诺无剧透。指定章节时不展示情节记录的最终回收结果和全书状态。事实仍受确认状态、依赖删除和有效期约束。

普通浏览不调用 LLM。点击“AI摘要”才使用当前模型执行一次结构化整理，输出最多 1,024 token，输入预算 12,000 token，并预先检查模型容量。摘要保存于已有任务记录；来源指纹相同直接复用，修改、删除或改变适用来源后显示过期。失败可取消或手动恢复，结果未知不会自动重发；任务提交、缓存复用与恢复均有幂等及同页任务互斥保护。

AI 摘要带来源链接，仅供辅助阅读，不自动成为确认事实、章节正文、对话历史或长期检索材料。Wiki 每页最多 24 条来源，单条最多 2,000 字符，来源总计最多 12,000 字符；状态历史按故事顺序保留当前范围内最近 100 条有效记录，排除章节删除或重排后失效的范围。超过范围明确提示部分内容，原始资料仍可打开。提及匹配是检索线索，不是语义关系或事实正确性的证明。

## 数据、回收站与备份

```text
backend/data/
  workspace.db                       # 只有项目注册元数据
  projects/<项目ID>/
    project.db                       # 正文、设定、版本、任务、总结与 FTS5
    assets/
    rag/chapter-continuity-ledger.md  # 单项目、单文件、按章节组织
    rag/vectors/vectors.db           # 可选，可重建
    backups/
```

账本是数据库总结的原子替换投影。请在界面编辑总结，直接改文件会在重建时被覆盖。文件只列当前有效总结，过期及替代记录保留在数据库。

素材删除立即退出检索，回收站保留 30 天；到期后在下次项目使用时自动清理。应用关闭时不运行后台定时器。仍被数据库关联引用的记录保留，直到解除关联。永久清理不是磁盘安全擦除，也不会删除旧备份。

恢复卷、章或场景时，其上级链必须存在且可用；请从父节点向下恢复，不会自动恢复祖先。已有孤立节点可通过明确修改上级（包括移至根目录）修复；校验失败不改变原回收期限或修订号。

“导出项目备份”下载一致性数据库快照、正文 Markdown、版本 JSON、素材与账本 ZIP。向量可重建，不必备份。完整灾备请停止服务后复制整个数据目录；恢复前也停止服务并先保留原目录副本。单项目 ZIP 暂无界面导入向导，勿覆盖在用数据库。

检测到旧共享 `novel-harness.db` 时自动备份并按小说复制，校验行数、外键、媒体哈希后注册独立 Vault；原库和原资产不删除。失败会阻止启动，可保留现场后重试。不要再对旧共享库执行 Alembic 迁移。

这是无认证、无磁盘加密的本机单用户服务，仅监听 `127.0.0.1`，不要暴露到局域网／公网。项目隔离针对应用数据流，不防御能读取磁盘的系统用户。RAG 能减少漂移，但不能保证模型永不矛盾。

## 验证

写作审校遇到已收到完整响应的格式或证据错误时，每阶段只修复一次，复用已完成初稿；完整章节通常 4 或 7 次模型调用，加入所有审校修复后最多 10 次，不含明确未发送的连接重试。未知结果、超时、认证、余额、限流和输出截断不会触发此修复。恢复时沿独立修复检查点继续，已完成修复不重复请求模型。当前写作与总结 Prompt 分别为 v6／v3，旧版未完成任务需按当前设置新建。接入支持 Chat Completions 的服务商时，流式输出会显式请求 usage；服务商未提供的统计不会当作零费用。

真实本地模型的文学质量单独验收，不以演示模式或单元测试替代。

模型设置的高级项可分别配置最大输出、上下文容量、总超时与兼容输出参数。输入预算包含实际消息和结构化 schema，并预留输出空间；Token 为保守估算，服务商 usage 可用时单独保留真实统计。章节总结若收到已知的结构/证据语义错误，只会进行一次严格证据修复；超时、断线、未知结果和预算错误不会自动重发。长章节在发出首个请求前计算整棵分段合并树，单任务最多 32 次模型调用（含一次可能的证据修复），超限直接停止。写作流水线与章节总结使用独立 Prompt 版本，修改一侧不会使另一侧的可恢复任务失效。成功或失败阶段只公开脱敏后的服务商、模型、耗时与 usage，不保存无效模型正文。远程接口必须接受非压缩响应（请求 `Accept-Encoding: identity`），避免压缩解码绕过内存上限。

新生成总结逐项保留原文证据，长章节分段处理后按检查点合并；内容检查的完整分段观察只供确定性校验，审计消息、建议和内部元数据不会进入后续 RAG、连续性账本或写作上下文。章节完成检查会核对当前章节范围内的全部有效确认事实，不只核对固定事实；发现严重冲突时暂停完成流程。完整章节流水线在初稿连续性和文风审校都无问题时保留初稿，不产生无意义重写；有问题时只采用保守方案重写一次，再进行一次连续性与文风综合终审。候选关联的开放 error/severe 冲突必须由作者明确确认后才能接受，并保留覆盖审计记录。只读证据不代表作者后来修改的总结已经再次被 AI 验证。账本写入失败不会回滚作者正文，可纯本地修复；旧未完成任务不自动套用新版 Prompt。

离线合成评测和固定规模性能测量（从 `backend` 运行，设置 `PYTHONPATH=src`）：

```powershell
.venv/Scripts/python.exe scripts/evaluate_quality.py
.venv/Scripts/python.exe scripts/evaluate_quality.py --long-memory
.venv/Scripts/python.exe scripts/measure_hardening.py
.venv/Scripts/python.exe scripts/measure_library.py
.venv/Scripts/python.exe scripts/measure_ledger.py
# 仅在明确需要时运行真实本机模型；不读取作者资料或密钥、不下载模型。
.venv/Scripts/python.exe scripts/evaluate_quality.py --real-model --endpoint http://127.0.0.1:11434 --model 已安装模型名
```

`--long-memory` 会建立并自动清理两个临时 SQLite Vault，以 300 章、约 42 万字符和 299 条总结验证远距记忆、未确认内容隔离、跨 Vault 隔离、章节时间状态、最近三章窗口和上下文预算；它不读取作者数据、不创建模型服务商，模型调用数为 0。

确定性评测不证明文学质量、语义抗注入或模型永不产生幻觉。

在仓库根目录运行唯一正式验证入口：


该入口会调用 `scripts\build.ps1`；构建脚本在安全检查后清理 `frontend\dist`，并将正式静态产物同步到 `backend/static`。不要用裸前端构建命令替代这一同步流程。
